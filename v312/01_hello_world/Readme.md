# Hello World Project

A simple Python project that prints "Hello World!" to the console. This project serves as a basic introduction to setting up and running a Python script.

## Project Structure

```
01_hello_world/
└── hello_world.py    # The main Python script
```

## Prerequisites

To run this project, you need to have Python installed on your system.

- **Python Version**: 3.12 (Recommended)
- **Operating System**: Compatible with Linux (e.g., Ubuntu 24.04), macOS, and Windows.

## Getting Started from Scratch

Follow these steps to recreate this project on your local machine:

### 1. Create the Project Directory
Open your terminal and create a folder for the project:
```bash
mkdir 01_hello_world
cd 01_hello_world
```

### 2. Create the Python Script
Create a file named `hello_world.py` and add the following code:
```python
"""
Author: Ahmet Aksoy
Date: 2026-04-16
Python 3.12 - Ubuntu 24.04
"""

print("Hello World!")
```

### 3. Run the Script
Execute the script using the Python interpreter:
```bash
python3 hello_world.py
```

## Expected Output
When you run the script, you should see the following output in your terminal:
```text
Hello World!
```

# Hello World Python Projesi

Konsola "Hello World!" yazdıran, basit ve yeni başlayanlar için uygun bir Python projesi. Bu proje, Python'a yeni başlayan herkes için en temel ilk adım olarak tasarlanmıştır.

## 🛠️ Ön Gereksinimler
- **Python**: Versiyon 3.12
- **İşletim Sistemi**: Ubuntu 24.04 (üzerinde geliştirilmiştir)

## 🚀 Kurulum
Bu proje, tüm öğrenme modülleri arasında tutarlılığı sağlamak için Python projeleri dizininin kökünde bulunan paylaşılan bir sanal ortam (virtual environment) kullanır.

Paylaşılan ortamı etkinleştirmek için, proje klasörünün içindeyken şu komutu çalıştırın:
```bash
source ../../e312/bin/activate
```

## 💻 Kullanım
Sanal ortam etkinleştirildikten sonra, script'i şu komutla çalıştırabilirsiniz:
```bash
python hello_world.py
```

**Beklenen Çıktı:**
`Hello World!`

---

## 📖 Kod Ne Yapar?
Proje, `hello_world.py` adında tek bir dosya içerir. Bu script, Python'da konsola metin yazdırmanın en temel yolu olan yerleşik `print()` fonksiyonunu kullanır.

## 🎓 Temel Kavramlar
- **`print()` fonksiyonu**: Bilgileri ekranda görüntülemek için kullanılır.
- **Docstring'ler**: Dosyanın başındaki üç tırnaklı dize, yazar, tarih ve ortam gibi meta verileri sağlamak için kullanılan bir docstring'dir.
- **Script Çalıştırma**: Bir `.py` dosyasının doğrudan terminalden çalıştırılması.

- Yok (bu proje sadece Python Standart Kütüphanesini kullanır).
